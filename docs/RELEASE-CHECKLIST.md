# Release Checklist

- [ ] Back up files and database.
- [ ] Verify WordPress and PHP requirements.
- [ ] Run PHP lint and JavaScript syntax checks.
- [ ] Run PHPCS, Theme Check, PHPUnit, browser/axe, and Lighthouse where available.
- [ ] Test Header/Footer, Homepage, Blog, templates, design modes, and Customizer publishing.
- [ ] Test WooCommerce on staging with disposable products and sandbox payment methods.
- [ ] Test keyboard navigation, focus, reduced motion, responsive widths, and RTL-sensitive layouts.
- [ ] Review SEO plugin ownership and structured-data output.
- [ ] Confirm no debug display, credentials, caches, or temporary artifacts are included.
- [ ] Record unavailable gates and remaining limitations before release approval.

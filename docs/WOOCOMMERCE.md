# WooCommerce

WooCommerce is optional. When active, the theme adds guarded presentation modules for shop archives, product cards, product pages, cart, checkout, account pages, homepage product sections, and the header cart indicator.

Commerce remains owned by WooCommerce: prices, variations, inventory, taxes, shipping, coupons, payment gateways, customer authentication, orders, and HPOS are not reimplemented by the theme. No payment credentials or custom order storage are used.

The available repository environment did not include an active WooCommerce installation, so live product, cart, checkout, Blocks, HPOS, and payment-gateway tests remain required on staging.

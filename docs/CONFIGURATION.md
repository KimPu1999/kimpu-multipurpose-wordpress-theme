# Configuration

1. Assign Primary Navigation and Footer Navigation menus.
2. Configure Header Builder, Footer Builder, Global Design, and Homepage Builder settings.
3. Assign a static front page and posts page if the site needs a separate blog route.
4. Add widgets to the Footer and Blog Sidebar areas when required.
5. Configure Blog Settings for archive, single-post, sidebar, sharing, TOC, and reading-progress behavior.
6. If WooCommerce is active, configure KimPu WooCommerce Design after confirming the store pages and payment/shipping settings in WooCommerce.

Customizer values are validated and existing saved values are preserved. Clear a page cache after publishing visual changes.

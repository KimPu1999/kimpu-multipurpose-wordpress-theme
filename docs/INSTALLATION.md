# Installation

KimPu Multipurpose is a classic PHP theme. Copy the existing `kimpu-multipurpose` directory into `wp-content/themes/`, activate it under Appearance → Themes, and configure menus and Customizer settings under Appearance → Customize.

Requirements declared by the theme are WordPress 6.6 or newer and PHP 7.4 or newer. WooCommerce is optional. The theme does not install plugins, migrate data, or create demo content.

Before updating an existing site, take a database and file backup and test the update on staging. Keep the previous theme version available for rollback.

# Customizer

The theme exposes separate panels for KimPu Global Design, KimPu Homepage Builder, KimPu Blog Settings, KimPu WooCommerce Design, and the existing Header/Footer/Social controls.

Controls use allowlists for layouts and modes, WordPress color sanitization, URL sanitization, numeric bounds, and text/textarea sanitization. The theme does not expose arbitrary PHP, JavaScript, CSS, or executable HTML settings.

Preview and persistence require a functioning WordPress Customizer session. Static checks in this repository verify setting registration and duplicate-ID safety; browser publishing and visual preview require a running WordPress installation.

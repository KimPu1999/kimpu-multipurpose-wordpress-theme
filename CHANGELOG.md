# Changelog

## 1.6.0 — Phase 7

- Added conditional performance and accessibility styles, print styles, responsive image sizes, hero-image preload support, and safe deferred loading for theme scripts.
- Added SEO-plugin ownership detection with conservative fallback descriptions, social metadata, and non-conflicting Organization/WebSite/BlogPosting schema.
- Added optional accessible breadcrumbs for pages, posts, archives, search, and taxonomy views; WooCommerce and supported SEO plugins retain ownership of their breadcrumb contexts.
- Improved mobile navigation with submenu ARIA controls, keyboard focus trapping, Escape handling, focus restoration, touch target sizing, and scroll locking.
- Added administrator-only read-only diagnostics under Tools → KimPu Diagnostics.
- Updated the theme version to 1.6.0 without changing WordPress or WooCommerce core behavior.

## 1.5.0 — Phase 6

- Added optional WooCommerce support with product gallery theme support and guarded integration modules.
- Added responsive shop, category, product-card, single-product, cart, checkout, and account presentation styles.
- Added Grid, List, and Modern Storefront shop layout controls, native product filtering, sorting, pagination, and empty states.
- Added optional homepage Featured Products, New Arrivals, Best Sellers, On Sale, Product Categories, and Promotional Banner sections.
- Added header cart icon/count integration using WooCommerce cart fragments without custom cart storage or totals.
- Added WooCommerce Customizer controls for shop, product cards, single products, cart/checkout, account pages, header cart, and homepage products.
- Preserved WooCommerce's native variation, stock, tax, shipping, payment, order, HPOS, Blocks, and customer-authentication behavior.

## 1.4.0 — Phase 5

- Added the KimPu Global Design Customizer panel with design presets, global colors, typography, layout, buttons/forms, spacing, responsive values, and advanced settings.
- Preserved legacy Phase 1 global setting IDs while moving their controls into the new panel; no duplicate Customizer setting IDs were introduced.
- Added safe CSS custom-property tokens for shared Header, Footer, Homepage, Blog, archive, page-template, Gutenberg, card, button, form, and pagination styling.
- Added Light, Dark, and System color modes with a keyboard-accessible frontend switcher, browser preference persistence, reduced-motion support, and flash prevention.
- Added system-safe font choices, fluid heading sizes, responsive container padding, fixed mobile/tablet/desktop breakpoints, and file-mtime asset versions.
- Updated theme.json editor content widths and palette alignment; theme version is now 1.4.0.

## 1.3.0 — Phase 4

- Added Grid, List, and Magazine blog listing layouts using the native WordPress main query.
- Added featured articles, category navigation, reusable post cards, list/magazine cards, archives, author profiles, search results, pagination, and optional blog sidebar widgets.
- Added single-post layouts with reading time, updated dates, Gutenberg-compatible content, table of contents, reading progress, sharing, author box, related posts, tags, comments, and previous/next navigation.
- Added Blog Settings Customizer panel with layout, metadata, single-post, TOC, progress, related-post, archive, and sidebar controls.
- Added responsive blog CSS and lightweight vanilla JavaScript for copy-link, TOC navigation, FAQ-independent reading progress, and reduced-motion-safe interaction.

## 1.2.0 — Phase 3

- Added the native Homepage Builder with twelve configurable sections and validated section ordering.
- Added responsive Hero layouts, native Page/Post content sources, empty states, and safe structured settings for features, statistics, and FAQs.
- Added eight reusable Classic Theme page templates plus Blank Canvas and Landing Page chrome controls.
- Added homepage-specific responsive design tokens and section presentation styles.
- Organized Homepage Builder settings into a named Customizer panel with per-section controls and added the homepage interaction script/page-template stylesheet.
- Preserved Phase 1 templates and Phase 2 header, footer, navigation, social, sticky-header, and Customizer settings.

## 1.1.0 — Phase 2

- Added selectable header and footer layouts.
- Added Header Builder, Footer Builder, Social Links, and Global Design Customizer sections.
- Added nested accessible navigation, mobile drawer/dropdown behavior, sticky header support, footer widgets, and inline social icons.
